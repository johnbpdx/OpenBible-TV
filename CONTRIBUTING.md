# Contributing to OpenBible-TV

Thank you for considering contributing to **OpenBible-TV**!  
We welcome contributions from everyone — developers, designers, theologians, testers, and Bible enthusiasts alike.

## Code of Conduct

By participating in this project, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md) (if added later). In short: be kind, respectful, and constructive.

## How Can You Contribute?

### 1. Reporting Bugs
- Open an [Issue](https://github.com/johnbpdx/OpenBible-TV/issues)
- Use the **Bug Report** template
- Include:
  - Roku model and firmware version
  - Steps to reproduce
  - Expected vs actual behavior
  - Screenshots if helpful

### 2. Suggesting Features or Improvements
- Open an [Issue](https://github.com/johnbpdx/OpenBible-TV/issues) with the **Feature Request** template
- Be as specific as possible (e.g., "Add support for Spanish Reina-Valera 1960")

### 3. Submitting Code Changes (Pull Requests)

1. **Fork** the repository
2. Create a feature branch:
   ```bash
   git checkout -b feature/amazing-feature
